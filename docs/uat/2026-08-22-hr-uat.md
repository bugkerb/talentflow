# HR UAT — 2026-08-22

## เป้าหมาย

ยืนยันว่า HR สามารถใช้งาน workflow หลักได้จริงในภาษาไทย โดยไม่เจอ dead click, ไม่หลงทาง และรู้ว่าต้องทำ action ถัดไปอะไร

## ผู้ทดสอบจำลอง

- HR-01: ผู้เริ่มงาน — เข้าระบบ, อ่าน dashboard, เปิดตำแหน่งงาน, ค้นหาตำแหน่ง
- HR-02: HR คัดกรอง — ค้นหาผู้สมัคร, เลือกตำแหน่ง, เริ่มค้นหา, ตัดสินใจผู้สมัคร
- HR-03: HR ผู้ดูแล pipeline — ติดตามผู้สมัคร, เปลี่ยนมุมมอง/สถานะ, ดูนัดสัมภาษณ์

## Acceptance criteria

| ID | Scenario | PASS เมื่อ |
|---|---|---|
| UAT-01 | เข้าสู่ระบบ | เข้าหน้า Dashboard สำเร็จ และเมนู Dashboard active ถูกต้อง |
| UAT-02 | Dashboard orientation | เห็นรายการที่ต้องทำและกดไปยังหน้าปลายทางได้ |
| UAT-03 | จัดการตำแหน่งงาน | ค้นหา/กรองตำแหน่งงานได้ และเห็นปุ่ม action ที่ใช้งานได้ |
| UAT-04 | สร้างตำแหน่งงาน | กรอกข้อมูลและบันทึกได้ หรือเห็น validation ที่บอกวิธีแก้ชัดเจน |
| UAT-05 | ค้นหาผู้สมัคร | เลือกตำแหน่งงานก่อนเริ่มค้นหา และเห็นผลลัพธ์ที่อ่านง่าย |
| UAT-06 | ตัดสินใจผู้สมัคร | อนุมัติ/รอตรวจสอบ/ปฏิเสธแล้วมี feedback และ state เปลี่ยนชัดเจน |
| UAT-07 | ติดตามผู้สมัคร | เปิดรายละเอียดผู้สมัครและเปลี่ยน stage ได้โดยไม่ dead click |
| UAT-08 | ตารางนัดสัมภาษณ์ | สลับมุมมองและเปิด action นัดหมายได้ |
| UAT-09 | Responsive | ที่ viewport มือถือ เมนูและ content ใช้งานได้ ไม่ชน/ล้นจอ |
| UAT-10 | ภาษาและความเข้าใจ | ไม่มีข้อความอังกฤษที่ไม่จำเป็น และปุ่มบอกผลลัพธ์ของ action ชัดเจน |

## วิธีรายงาน feedback

ทุก finding ต้องระบุ: UAT ID, URL, ขั้นตอนทำซ้ำ, ผลที่คาดหวัง, ผลที่เกิดจริง, severity (blocker/high/medium/low), และหลักฐาน screenshot/console ถ้ามี

## Deterministic loop

`UAT execute → record PASS/FAIL → developer fix → rerun failed scenario → repeat until all required scenarios PASS`

ห้ามสรุปว่าเสร็จจากการอ่าน source อย่างเดียว ต้องมี browser evidence สำหรับทุก scenario ที่รายงานว่า PASS

## ผลรอบแก้ไข

- UAT-04: PASS หลังเพิ่ม inline validation, `aria-invalid`, `aria-describedby` และ feedback เมื่อส่งฟอร์มว่าง
- UAT-10: PASS หลังเปลี่ยน `รายละเอียดงาน (Job Description)` เป็น `รายละเอียดงาน`
- Regression: UAT-01 ถึง UAT-03, UAT-05 ถึง UAT-09 ยังคง PASS จาก browser evidence ของ HR agents
